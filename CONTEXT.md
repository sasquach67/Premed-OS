# Premed OS Academics

## Glossary

- **Schedule entry** — a syllabus-derived planned class date and scope. It describes course timing; it is not a study topic or evidence that the class happened.
- **Learning standard** — a stated syllabus learning objective or outcome. It is the stable, internal study topic because it names what the course says a student should learn and may be assessed on.
- **Lecture** — one student-owned class session, identified by its date and title. A lecture may contain a pasted transcript and attached source material.
- **Lecture material** — a course or student file explicitly attached to one lecture. It stays a normal class file, so its provenance and reuse remain intact.
- **Activated topic** — a learning standard connected to a recorded lecture or student study action. Only an activated topic can enter the recall workflow.
