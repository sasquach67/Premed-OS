# Global Interactions

## Command palette

Search and act across records and navigation.

Supported concepts:

- People
- Organizations
- Experiences
- Courses
- Schools
- Essays
- Notes
- Files
- Tasks
- Commands

## Quick add

Universal quick-add with context-sensitive defaults.

## Review queue

Centralized inbox for:

- Missing data
- Duplicates
- Overdue tasks
- Sync conflicts
- Stale records
- Pending imports
- Unlinked files
- Archive candidates

## Bulk operations

Support archive, restore, tag, status change, assign term, link organization, export, and delete where compatible.

## Saved views

Save filters, sorting, grouping, columns, date range, and density.

## Undo and recovery

Provide immediate undo, trash recovery, version history, and merge reversal where feasible.

## Focus mode

Allow users to complete one task without dashboard clutter.

## Autosave and sync

Show clear states:

- Saved
- Saving
- Offline
- Syncing
- Conflict
- Error
