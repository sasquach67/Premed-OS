## Name screening boundary

The USPTO describes an exact-wording search as only a preliminary “knock-out” search and says not to stop there. A proper clearance review must also examine similar wording, spelling, pronunciation, commercial impression, and related goods or services, plus relevant non-federal sources.

Because that broader review is a legal/publication decision, this repository must not mark the `Premed OS` name cleared based on an internet search or an exact-name database query alone.

## Required owner action before unrestricted public beta

1. Search the USPTO Trademark Search system for exact and similar forms of `Premed OS`, `PremedOS`, and other likely phonetic/spacing variants.
2. Review potentially similar marks in software, education, study tools, health education, and adjacent services—not only exact matches.
3. Search state trademark records, company/product use, app stores, search engines, and relevant domain names.
4. Record the reviewer, date, search terms, candidate conflicts, and decision.
5. For a production brand decision, obtain qualified trademark counsel if there is any plausible conflict.
