Frame 2. This is the whole argument. Clicking a building shows what you have there, across pillars — a clinical shift, a physician, an open letter request — and every row deep-links to the page that owns it. The map owns nothing but locations. Open in UNC maps hands wayfinding back to Concept3D, which is the one thing we should never rebuild.
Fork C, drawn. No tile provider, no MapLibre, no Protomaps, no API key, no backend — this is an SVG with click handlers. It works signed-out and offline, and it is the only version that can wear HQ's palette rather than looking like a general-purpose map in a warm-dark frame.

Costs, stated honestly. Someone has to draw it, and every new building is hand work. Accuracy is approximate by design. Off-campus records cannot appear and live in the rail instead. And it needs an explicit exception to 04's graphic vocabulary before it can ship.

Per 04 §0a this file is a flow reference. Structure and behaviour are the point; the app's real tokens and components are the visual law.
