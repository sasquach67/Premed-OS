# MCAT flat tabs — draft mockup notes

This source draws the five remaining MCAT tabs in the signed-in dark shell.

- **Content** combines mastery tracking with the phase-aware Bookshelf. Bookshelf is not a tab.
- **Questions** is a source-aware door, not a fake or AI-generated QBank. It includes M2M drills as the only in-app generated practice.
- **Mistakes** is the Capture → Diagnose → Drill loop, with separate science/CARS diagnostic logic.
- **Stats** shows full-length trend, per-section indicators, and a descriptive stamina signal only when enough full lengths exist.
- **Advisor** is conversational and permission-first: propose, explain, confirm, then modify the deterministic plan.

Each page has A/B/C layout treatments in the variant lab; those treatments do not alter the underlying behavior.
