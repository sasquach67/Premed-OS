# MCAT plan — draft mockup notes

The Plan is an editable, phase-aware study schedule:

- Foundation → Practice → Polish → Full-length phases;
- named daily sessions, day-by-day to the test;
- full lengths carry a protected review block immediately after;
- an honest projected-versus-goal gap and a rebuild path;
- optional hours target, never prefilled and never treated as readiness.

This is a draft mockup, not implementation authorization.
