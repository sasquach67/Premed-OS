# MCAT dashboard — mockup notes

## Encoded decisions

- The primary action is always a study session, not an opaque score forecast.
- Readiness is explained through logged full lengths and study activity.
- One clear next block leads; supporting section status stays subordinate.
- The sample score is illustrative UI data only, not a predicted outcome.

## Variants

- **A — Study home:** today’s work leads.
- **B — Session runway:** the current session expands into the working surface.
- **C — Scoreboard + plan:** measured progress and the plan share the first read.
