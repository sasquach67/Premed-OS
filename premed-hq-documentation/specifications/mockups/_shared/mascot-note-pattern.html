Restraint — where it must NOT appear
Errors, failures, or destructive confirmations. A cartoon delivering "couldn't save your work" or "delete 12 records?" reads as flippant. Use the scoped-error pattern and Alert Dialog.
As a UI icon or control. Illustration only — never a button, nav item, or inline label (CLAUDE.md).
More than one per view. Two mascot notes on a screen turns character into noise.
Repeating forever. Teaching notes fire once per concept, then dismiss permanently. Generic encouragement on every visit is nagging.
Manufactured praise. Milestone notes fire only on real thresholds — never "nice job opening the app."
Cite the source when there is one. r/premed, an uploaded guide, an Atlas-ingested source. Unsourced advice carries no label rather than a fake one.
