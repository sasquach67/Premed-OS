# Application workspaces — mockup notes

This configurable source completes three previously undrawn product families.

## School List

- **Explore** keeps official roster facts, optional sourced profiles, and student-owned planning facts visibly separate.
- **Track** owns the student's list, why each school is present, personal tier, application service, record-presence prerequisite check, letters routing, service-level primary, pasted secondary prompts, elapsed days, and export.
- It never fetches or guesses secondary prompts, invents admissions-profile data, or converts missing data into a score.

## Essays & Story Bank

- **The bank** opens newest-first with a seven-theme count rail and includes orphan journal entries.
- **Essays** holds prompt text, school, limit, status, due date, and live count.
- **Writing desk** keeps the prompt, filtered owned material, draft, and cited direction in one frame. Suggestions provide an arc, never paste-ready prose and never edit the student's work.

## Letters & Mentors

- **People** is the aggregate relationship door; instructors arrive from Academics automatically and mentors need no request status.
- **Dossier** contains public-work links, student-pasted excerpts, shared history, running notes, and a subject to raise—never personal surveillance or fetched profiles.
- **Requests** appears only when the cycle is near and keeps three child states, the ready-only writer packet, waiver, lead-time context, and one-time thank-you copy. Premed OS never sends or stores the letter.
