# Academics · superseded prototype routes

**Status:** historical record · not an active approval candidate

## Lecture Capture — CUT

The `academics-lecture-capture` source remains on disk for traceability, but it
is removed from active Academics navigation. The current product route accepts a
student-provided transcript and other course materials; Premed OS never records,
uploads, stores, or transcribes lecture audio.

## Canvas-specific material views — CUT by U-12

Canvas sync, Canvas tokens, Canvas APIs, and Canvas calendar-feed views are no
longer active mockup routes. U-12 records Canvas as unreachable for this product
and says not to spec, propose, or prototype a sync. Manual class records,
student-provided syllabus text, pasted material, and ordinary external links
remain valid and are not removed by this ruling.

The old source frames remain recoverable as historical context only; they must
not be promoted or translated into app functionality.
