# Overview projection states

**Status:** PROPOSED · **Scope:** the single permitted pacing/projection
disclosure inside an owning Overview panel.

## Behaviour

- A panel with insufficient attributable, dated evidence says **“Not enough
  dated work yet”** and names the next record the student can add. It does not
  show a zero, bar, estimate, or judgement.
- When evidence exists, the normal state stays collapsed behind **Show
  projection**. The expanded calculation is local to the owning panel and can
  be dismissed back to that quiet state.
- The expanded state names its evidence window, exact logged value, measured
  pace, remaining target, and plain calculation. It never silently changes a
  record or claims a future result.
- The populated values on this board are an explicitly marked **example
  calculation** for visual review. The app must bind the same layout only to
  real dated, attributable records; without them it uses the unavailable
  state.

## Appearance

- **One treatment only.** These are states of one compact 5-column bento panel,
  not A/B/C layout experiments and not a new Overview tab or ninth block.
- Unavailable is a small solid inset beneath the open domain row: restrained
  warning left rule, a small dash chip, and one factual sentence. It has none
  of the visual weight of an error.
- Collapsed uses a quiet rounded **Show projection** pill. It sits at the row
  edge and does not become a chart, meter, or new card.
- Expanded stays a solid, bordered inset at the exact same anchor. Four compact
  fact cells make the evidence traceable, followed by a one-line formula and a
  low-emphasis dismiss control. The card remains solid-with-depth; no glass.
- On mobile the cells stack but the state order stays unavailable → collapsed
  → expanded. Motion is an opacity/height disclosure with a reduced-motion
  instant equivalent.

## Deliberately absent

No readiness label, score, composite, ranking, percentage bar, generic
timeline, default target, invented future date, or reassurance language. A
projection is not displayed when the evidence model cannot support it.
