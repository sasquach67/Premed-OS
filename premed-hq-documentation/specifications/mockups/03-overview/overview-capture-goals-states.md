# Overview Capture, Quarterly Goals, and resilience states

**Status:** APPROVED · **Scope:** Capture input paths, Quarterly Goals, and shared widget resilience.

## Behaviour

- **Settled destination:** v1 Capture saves an untyped thought, pasted URL, or attached file to **Story Bank**. The local-only control is per-entry. Atlas is a visibly reserved connection slot, not a route or a second destination.
- A goal is student-confirmed as either check-off or measured. Measured copy names actual recorded evidence and a student-set target; manual goals remain a checkbox.
- Every widget loads and fails independently. A failure keeps the rest of Overview alive and offers a local retry. Mobile keeps Capture high in normal flow.

## Appearance

- **One treatment only.** These are real states of existing controls, not alternative layouts.
- Capture uses a compact solid field with small adjacent link/file affordances and a quiet privacy line. Its result is a short, green-accented confirmation—not an inbox.
- Goal rows share the main Overview card geometry. The measured/check-off tag is a small vocabulary cue, never a bar or score.
- Loading uses local skeleton lines; error uses a restrained destructive left rule; neither takes over the page.

## Deliberately absent

No live Atlas route, capture triage, streak, score, composite readiness, automatic goal classification, floating mobile capture control, or full-page spinner.
