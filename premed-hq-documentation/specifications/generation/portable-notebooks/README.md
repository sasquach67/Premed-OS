# Portable notebook instruction builder — draft 4

Canonical Markdown owns learning rules. This directory provides reproducible assembly and deterministic structural checks, not a second prose rule set. Generated copy prompts contain the applicable rule text, editable class/request input, and the exact v4 JSON Schema; exact v2/v3 schemas remain compatibility inputs. No real class source was inspected or trial generated by this tooling.

## Build and verify

Run from the canonical repository root. The output may be any separate directory. Python standard library is sufficient for building; verification uses the independently maintained `jsonschema` Draft 2020-12 implementation.

```sh
python3 premed-hq-documentation/specifications/generation/portable-notebooks/build_prompts.py --canonical-root . --output /tmp/notebook-instruction-output
python3 premed-hq-documentation/specifications/generation/portable-notebooks/build_fixtures.py --output /tmp/notebook-instruction-output
python3 premed-hq-documentation/specifications/generation/portable-notebooks/build_feasibility_case.py --output /tmp/notebook-instruction-output/feasibility-case
python3 premed-hq-documentation/specifications/generation/portable-notebooks/build_conversation_examples.py --output /tmp/notebook-instruction-output
python3 premed-hq-documentation/specifications/generation/portable-notebooks/build_revision_cases.py --output /tmp/notebook-instruction-output/revision-case
python3 premed-hq-documentation/specifications/generation/portable-notebooks/build_standardization.py --canonical-root . --output /tmp/notebook-instruction-output
python3 -m venv /tmp/notebook-validation
/tmp/notebook-validation/bin/python -m pip install -r premed-hq-documentation/specifications/generation/portable-notebooks/requirements-validation.txt
/tmp/notebook-validation/bin/python premed-hq-documentation/specifications/generation/portable-notebooks/check_package.py --canonical-root . --output /tmp/notebook-instruction-output
```

`build_schema.py` reconstructs the adjacent schema. That file is an exact snapshot of the coordinator's agreed v2 contract; change it only in coordination with the app owner. `validate_package.py --schema PATH PACKAGE...` validates supplied JSON files separately. It rejects unresolved/cross-entry references, inconsistent excerpt ownership, invalid source-use claims, unsupported mastery links, broken revision arithmetic, mismatched table widths, and selected learning-shape violations. It cannot verify actual source text, entailment, comprehensive coverage, learning quality or UI behavior.

`canonical-manifest.json` records canonical paths, full source hashes, selected-fragment hashes, tooling hashes, output hashes, and deliberate extensions. `prompt-composition.json` gives the app the exact tokens and substitution contract. `validation-report.json` records checks and limits.

## App integration contract

Maintain exactly three prewritten goal templates derived from canonical Markdown. Goal selection retrieves the chosen static template; no AI API generates or rewrites prompts. Local placeholder insertion and student notes are plain-text operations. The student subsequently uses that prompt in their preferred AI to generate notebook content.

Use a regex replacement callback or equivalent single-pass algorithm; do not repeatedly replace tokens in already inserted user text. `compose()` in build_prompts.py is a reference implementation. JSON-encoding handles quotes and newlines; it does not turn source text into instructions or give access to named attachments.

The completed prompt string is the single value for preview, clipboard and UTF-8 Markdown download. Keep each surface byte-identical. Selected saved-file titles and user-listed attachments can populate MATERIALS, but the app must explain that the original material still needs to be supplied to the chosen AI. SCOPE may include the selected lessons and scope authority. Existing exported JSON can populate or be identified in REVISION_INPUT; naming it is not reading it.

Exact v2/v3 schemas remain separately available for compatibility and saved baselines.
